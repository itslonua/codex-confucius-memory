# Continuation memory benchmark: automatic restore

This is a second, separately reported protocol motivated by the completed optional-retrieval run: agents rarely chose to call restore/search. It reuses the same frozen synthetic fixtures, tasks, learning transcript, production-compressed memory store, model/settings, hidden deterministic graders, seed, and three paired repeats. It does not replace or alter the first 18-trial run.

Before each trial, call the production `codex-memory restore` against that arm's store using session ID `effect-learning` and the trial's project cwd. Preserve the exact restore JSON and inject the exact `hookSpecificOutput.additionalContext` into the task prompt, identically formatted in both arms. Baseline restore points to an empty store; treatment restore points to the frozen generated store. This models automatically restored continuation context, not an agent-selected search-only intervention. The agent may still search/read project notes using the same instructions and tools. Record the base and injected prompt hashes and exact context per trial. Include restore latency in end-to-end elapsed time.

The production store is keyed by canonical cwd. Reuse the original, now-absent fixture cwd recorded in the first run's memory search preflight so restoration resolves the same project note. Refuse to proceed if that temporary root already exists, then clean up only the directory this run creates. Before model calls, verify that empty-store restore contains no session summary or project note index, while frozen-store restore contains both; verify production search returns the note and read returns the exact frozen note content. Abort preflight if any assertion fails.

The treatment context includes a historical session summary and note index, which may influence behavior before a note read. Report it as continuation-memory exposure. Do not attribute its effects solely to project-note search. Do not change tasks, prompts, graders, protocol, or scoring after the first continuation trial. Preserve every trial, including failures. Run all 18 trials regardless of intermediate outcomes.
